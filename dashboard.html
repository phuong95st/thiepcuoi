# Khách mời Xác nhận RSVP Lời chúc mừng Thời gian Thao tác

Chưa có dữ liệu nào phù hợp với bộ lọc.

Đồng Bộ RSVP Trực Tiếp Lên Google Sheets

Khi kết nối Google Sheets, mỗi khi bất kỳ khách mời nào bấm "Gửi Lời Chúc Mừng" từ điện thoại của họ, dữ liệu sẽ ngay lập tức được ghi vào trang tính Google Sheets của bạn!

Đã lưu Webhook URL thành công!

  1. Tạo một Google Sheet mới, đặt tên: Khách Mời Đám Cưới Phương Quỳnh.
  2. Vào menu Tiện ích mở rộng (Extensions) → Apps Script.
  3. Xóa hết mã cũ và dán đoạn mã sau vào:
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Thời gian", "Họ và tên", "Xác nhận RSVP", "Lời chúc"]);
    }
    sheet.appendRow([data.date, data.name, data.presence, data.comment]);
    return ContentService.createTextOutput(JSON.stringify({status: "ok"})).setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Bấm Triển khai (Deploy) → Triển khai dưới dạng ứng dụng web mới (New deployment).
  2. Chọn: Người có quyền truy cập (Who has access) = Bất kỳ ai (Anyone) → Bấm Deploy.
  3. Copy đường dẫn Web App (kết thúc bằng /exec) dán vào ô bên trên và bấm Lưu Cấu Hình!
